ProteinDSL

a query language for protein records — local CSV or live UniProt

Program

Ctrl+Enter

Language reference

LOAD "dataset/proteins.csv"
Read the bundled CSV. File access is confined to dataset/.
LOAD UNIPROT "<query>" [TOP n]
Live UniProt REST search, e.g. insulin AND organism_id:9606. Up to 500; responses are cached.
FIND proteins
Query the loaded records. Every clause below is optional.
SEARCH "text"
Case-insensitive substring scan over every attribute, sequences included.
WHERE a = "x" AND len > 300 OR ...
AND binds tighter than OR. Operators: = != > < >= <=; ordering ones only on length.
SORT BY <field> [ASC|DESC]
Ordering. Numeric for length, case-insensitive text otherwise.
TOP n
Keep only the first n results.
DISPLAY <fields> | COUNT
Choose columns, or report the number of matches. Default is all columns.

Attributes: proteinid, name, organism, length, function, sequence. Note = on text is an exact (case-insensitive) match — use SEARCH for partial text.
